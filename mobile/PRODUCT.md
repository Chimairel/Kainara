# KAINARA mobile

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

User-selected React Native with Expo and TypeScript. Expo Router owns navigation.
Android is the first verification target; iOS remains a supported code target
pending actual Apple-device testing and store setup.

## Users

Existing and new KAINARA members checking meals, recording food and water,
reading their nutrition report and monitoring progress on a phone.

## Product Purpose

Provide native member workflows backed by the existing KAINARA API. Staff use
the existing website during this first mobile phase.

## Brand Commitments

The owner confirmed the existing cream, pine-green and orange identity. Adapt
the current member dashboard's content order to native navigation and controls.
Preserve Nara and existing food imagery, attribution and review wording.

## Capabilities and Constraints

Use encrypted device storage for refresh sessions. Do not embed database,
provider or signing secrets. Planning and clinical gates remain on the API.
Explicit confirmation precedes paid AI requests; no automatic write replay.
Deployment, Google-native OAuth registration and push credentials remain separate
release work. Do not test against the demo database to develop this app.

## Accessibility & Inclusion

Respect safe areas, system text scaling, system Back and appearance. Controls
have descriptive accessibility labels and at least 48dp touch targets.
