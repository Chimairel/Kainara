# KAINARA

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Members plan meals and record nutrition, water and weight. Nutritionists review
member cases and meals; administrators manage the platform. The first native
mobile application is for members; staff continue using the website.

## Product Purpose

Help members make practical food choices using personalized meal plans, Filipino
food composition references, intake tracking and recorded nutritionist reviews.

## Capabilities and Constraints

The Next.js website and Express/Prisma API remain separate. Meal eligibility,
report acknowledgment, clinical holds, exact approval reuse and credit admission
are server-owned. A mobile client must not grant approvals or infer suitability.
Hosted functional tests use staging only; no demo API tests or data changes.

## Brand Commitments

Retain KAINARA's current identity and Nara assets. On October 23, 2026 the owner
confirmed the existing visual style and a member-first React Native/Expo app.

## Evidence on Hand

See DESIGN.md, the executable website and docs/NUTRIMIND_ENGINEERING_RECORD.md.
Recorded implementation evidence is not clinical validation or deployment proof.

## Product Principles

- Keep personal records and historical reviews intact.
- Explain prerequisites and provide an actionable next step.
- Distinguish estimates, recorded facts and professional decisions.
- Preserve the website while adding a native member client.
