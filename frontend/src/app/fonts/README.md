# Bundled fonts

These variable TrueType files are bundled for next/font/local, avoiding Google font downloads during development or builds. Each font keeps its adjacent SIL Open Font License file.

Downloaded from the official Google Fonts repository on 2026-10-05:

- [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans): DMSans[opsz,wght].ttf
- [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans): PlusJakartaSans[wght].ttf
- [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit): Outfit[wght].ttf
- [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono): JetBrainsMono[wght].ttf

The font family variables are preserved in the root layout. Font assets total approximately 714 KB before compression; Next generates locally served font files.
